# 📊 Procesamiento Masivo de Datos (Big Data) para Análisis Comercial

> 🚀 *Transformando datos transaccionales crudos en inteligencia de negocios mediante tecnologías Big Data.*

---

## 🐍 1. Generación y Estructuración de Datos
Generar y estructurar **50.030 registros** en 4 archivos CSV mediante **Python**. 
* 📝 **Simulación realista:** Creación de datos de clientes, productos y facturación para construir una base transaccional apta para análisis masivo. 
* 🛡️ **Validación:** Para garantizar un entorno realista, se aplicaron estrictas reglas de negocio, lógica financiera de margen de ganancia e integridad referencial durante la creación de los datos.

## ⚙️ 2. Automatización e Integración 
Automatizar la integración de catálogos y transacciones mediante el ecosistema Big Data: **Hadoop HDFS**, **Java MapReduce** y **PySpark**.
* 🔗 **Transformación:** Ejecución de *joins* y transformaciones complejas para consolidar información comercial sin necesidad de procesamiento manual. 
* 💾 **Exportación:** El pipeline incluyó la inyección automatizada de los indicadores consolidados hacia tablas de una base de datos relacional **MySQL**.

## 📈 3. Análisis Comercial y Descubrimiento de KPIs
Analizar datos utilizando **PySpark DataFrames** mediante agrupaciones, sumatorias y ordenamientos para obtener **KPIs de ventas** cruciales para el negocio.
* 🏆 **Producto Líder:** Se identificó a la **Cama** como el producto estrella, logrando **639.876 unidades vendidas** y generando **$1.855.640.400** en ingresos totales. 
* 📊 **Métricas Detalladas:** El análisis profundizó en el rendimiento del negocio calculando métricas como el total recaudado por mes, por categoría de producto y el volumen físico de inventario despachado.
