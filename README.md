# Procesamiento Masivo de Datos (Big Data) para Análisis Comercial
Generar y estructurar 50.030 registros en 4 archivos CSV mediante Python. Simular datos de clientes, productos y facturación para construir una base transaccional apta para análisis masivo. Para garantizar un entorno realista, se aplicaron estrictas reglas de negocio, lógica financiera de margen de ganancia e integridad referencial durante la creación de los datos.
Automatizar la integración de catálogos y transacciones mediante Hadoop HDFS, Java MapReduce y PySpark. Ejecutar joins y transformaciones para consolidar información comercial sin procesamiento manual. Adicionalmente, el pipeline incluyó la exportación automatizada de los indicadores consolidados hacia tablas de una base de datos relacional MySQL.
Analizar datos con PySpark DataFrames mediante agrupaciones, sumatorias y ordenamientos para obtener KPIs de ventas. Identificar al producto líder (Cama) con 639.876 unidades vendidas y $1.855.640.400 en ingresos. El análisis profundizó en el rendimiento del negocio calculando métricas detalladas como el total recaudado por mes, por tipo de categoría y el volumen físico despachado.
